# 订单信息打印机

Chrome Manifest V3 扩展，用于在跨境卖货平台订单发货列表页提取选中的订单文本，并生成 TEMU 物流打印单。

## 功能

- 在订单页面选中文本后，通过右键菜单打印订单信息。
- 打印前输入袋数，范围为 1-10。
- 从选中文本中提取物流方式、物流单号、收货仓库、货号和发货数量。
- 自动合并相同货号的数量。
- 在 popup 中配置店铺名称和店铺代号。

## 店铺配置

popup 中内置六个默认店铺：

- `Tongzhou Shoe Industry`
- `JIAN MIN SHOES AND CLOTHING`
- `XiaoQu Kids Shoes`
- `JianHui Shoes`
- `Coastal Steps`
- `Zen Fee`

默认店铺不能删除，避免核心业务映射丢失；但可以修改对应的店铺代号。用户也可以新增自定义店铺映射，自定义店铺可以删除。

配置保存在 `chrome.storage.local` 中。

## 开发说明

订单文本解析逻辑目前保持原有规则不变，集中在 `background.js` 的 `extractOrderInfoFromText` 函数。后续如果商家后台订单文本格式变化，再统一优化该函数中的正则规则。

`js/text.js` 当前未被 `manifest.json` 引用，主打印流程不会加载它。该文件看起来是混淆/打包后的脚本，末尾包含对商家后台接口的请求逻辑。由于它后续可能用于后台相关功能，当前暂不删除；如果未来确认无用，再单独清理。

## 本地加载

1. 打开 Chrome 扩展管理页。
2. 开启开发者模式。
3. 选择“加载已解压的扩展程序”。
4. 选择本项目目录。
